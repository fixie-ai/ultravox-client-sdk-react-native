# ultravox-client-sdk-react-native
React Native client SDK for Ultravox.

## Installation


```sh
npm install ultravox-react-native
```


## Usage


```js
import { multiply } from 'ultravox-react-native';

// ...

const result = await multiply(3, 7);
```

## Testing SDK Changes

This repo includes a basic example application that can be used with the SDK. To run it from the main directory:

```bash
npm install --force
cd example
npm run start
```

An Expo server will start, from which you can open web, Android, or iOS using the commands provided.
